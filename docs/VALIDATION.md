## 开机自动启动

通过固定 Applications 路径的最终应用验证 `SMAppService.mainApp`，未注册临时构建副本：

- 测试前关闭。系统最初返回 `notFound`，复选框允许重新注册，不误判为应用未安装或禁用首次勾选。
- 点击「开机自动启动」后真实服务状态为 `enabled`，复选框勾选并显示「已启用」。
- 通过浮层「退出 StatPeek」退出，再打开安装应用；进程 PID 改变，启动项仍启用。
- 取消勾选后真实服务状态为 `notRegistered`，浮层保持打开。
- 再次退出并打开；启动项仍关闭，恢复测试前设置。
- 安装副本浮层连续采样期间宽度始终为 `107 × 24` 点，指标持续变化。
