# App icon

The app icon uses a dark navy tile and two rows of colorful status indicators, reflecting StatPeek's compact two-row menu bar layout. It is separate from the tiny SF Symbols used beside live metrics.

Generated with the built-in imagegen tool. The master image is exported into the macOS AppIcon asset catalog at all required resolutions.

## Generation prompt

Use case: logo-brand. Asset type: production macOS application icon for StatPeek, a compact menu bar system monitor. Create a single square 1024x1024 icon: a premium deep midnight-navy rounded-square tile with a subtle satin glass surface, centered on a fully transparent exterior. Inside the tile, a simple precise dashboard mark: two horizontal rows, each with two compact status indicators, forming a clean 2x2 arrangement. Each indicator consists of a tiny clean rounded bar-chart or meter glyph followed by a short horizontal rounded readout stroke. Use cyan-blue top left, amber top right, violet bottom left, mint-green bottom right. Bold restrained shapes, very readable at small sizes, balanced negative space, subtle dimensional lighting and crisp edges. No lettering, numbers, words, watermark, computer screen, complicated circuitry, extra objects, background scene, or icon grid. Deliver only one centered icon, no mockup. The rounded tile fills about 88 percent of the canvas, with transparent margins and no cast shadow outside the tile.
